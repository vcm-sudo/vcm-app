Política de privacidade — vcm

O vcm é um aplicativo de uso pessoal, usado apenas pela conta Google do próprio autor, Vinícius Campos de Molla.

  • Acessa o Gmail dessa conta para ler, enviar e organizar mensagens, sempre de forma automatizada em um computador pessoal.
  • Os dados ficam nesse computador e no próprio Gmail. Nada é vendido, compartilhado com terceiros ou usado para publicidade.
  • O uso de dados recebidos das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
